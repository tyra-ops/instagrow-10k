INSTAGROW 10K – NAKED EDITION (V2.0)
-----------------------------------
Enthalten:
- Mobiloptimiertes Dashboard
- Lokaler Follower-Zähler bis 10.000
- Caption-Vorbereiter für Naked-Bike-Content
- 3-Post-Wochenplan mit Checkliste
- Manuelle Wochenmetriken
- Freigabe-Status und Text kopieren

WICHTIG:
Dies ist ein funktionsfähiger Frontend-Prototyp. Er ist NICHT mit Instagram/Meta verbunden,
veröffentlicht nichts automatisch und generiert keine Follower. Daten werden lokal im Browser
gespeichert. Die Textvorlagen sind regelbasiert, kein eingebautes KI-Modell.

Auf dem iPhone:
1. Die Dateien auf einen HTTPS-Webhost hochladen (z. B. einen eigenen statischen Hosting-Dienst).
2. Die veröffentlichte HTTPS-Adresse in Safari öffnen.
3. Teilen > Zum Home-Bildschirm > Hinzufügen wählen.
4. Für die Web-App-Funktion ggf. „Als Web-App öffnen“ aktivieren.

Eine echte Meta-Anbindung benötigt eine Meta-Developer-App, OAuth-Berechtigungen und einen
sicheren Server für Zugriffstokens. Niemals Passwörter oder Tokens in diese HTML-Datei schreiben.
